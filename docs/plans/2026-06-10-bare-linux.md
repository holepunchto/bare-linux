# bare-linux Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An example Linux app that embeds the Bare runtime via bare-kit to run the same peer-to-peer shared switch as bare-macos, with a native host written in C.

**Architecture:** The JavaScript half (Hyperswarm worklet, switch logic, schema) is copied verbatim from bare-macos - it is platform-agnostic. The native half is rewritten in C against bare-kit's C API (`bare_worklet_*`, `bare_ipc_*`) instead of Swift, and the typed RPC client is generated by hrpc-c instead of hrpc-swift. The build is driven by `bare-make` + CMake instead of `xcodebuild`.

**Tech Stack:** C99, `bare-kit` (C worklet API, consumed as a prebuilt `libbare-kit.so`; headers via `bare-headers` + forward-declaration), `bare-make` / `cmake-bare` / `cmake-fetch`, `bare-link` + `bare-pack` (`--preset linux`), `librpc` + `libcompact` + `hyperschema-c` + `hrpc-c` for typed RPC, GTK4 for the eventual UI.

---

## Dependency reality - read this first

bare-linux's **native boot and IPC layer has no blockers** and can be built today. Its **typed RPC layer is gated** on upstream work that does not exist yet:

| Upstream gate                            | State today                                                                                       | Blocks                                                                                                                                                                                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `libbare-kit.so` Linux prebuild          | **Shipped** as of bare-kit PR #74 - `linux/<arch>/libbare-kit.so` in the release `prebuilds.zip`. | Nothing - Phase 0 fetches it (Task 0.1).                                                                                                                                                                                              |
| bare-kit C headers                       | Prebuilds ship **libraries only** (bare-kit decision, PR #74).                                    | Nothing - the host forward-declares the small bare-kit API it calls (RN-style), and gets real `bare`/`uv` types from the `bare-headers` npm package. The bare-kit "clean public C API" cleanup is **not** a blocker - it is optional. |
| `librpc` lib A (fixed-width types)       | Bug confirmed in `librpc/src/rpc.c:219`; fix is specced in `hrpc-c/SPEC.md`. Not landed.          | Phase 1                                                                                                                                                                                                                               |
| `hrpc-c` PRs 1-2 (unary + event codegen) | `hrpc-c` repo is spec-only (no `index.js` yet).                                                   | Phase 1                                                                                                                                                                                                                               |
| `librpc` lib C (`rpc_client_t` runtime)  | Proposed in the `hrpc-c/SPEC.md` review amendments. Not landed.                                   | Phase 1 (the host's request/response routing)                                                                                                                                                                                         |

**Consequence:** Phase 0 (native boundary) is the entire near-term scope and is the highest-risk, highest-value part - it proves `libbare-kit.so`, bundle loading, and the IPC byte channel on Linux. Phases 1-2 are sequenced behind the gates above and are outlined, not step-detailed, because the exact hrpc-c generated API is still settling (the SPEC amendments are proposed, not merged). Re-resolve Phases 1-2 to bite-sized tasks once hrpc-c PR 1 lands.

The switch demo uses only **unary** (`set-state`) and **send-only event** (`new-state`, `peers-changed`, `info`) handler kinds - confirmed in `bare-macos/spec/hrpc/hrpc.json`. It needs hrpc-c PRs 1-2 only, never the streaming PRs (4-6) or `librpc` lib B.

- [ ] **Step 3: Forward-declare the bare-kit API** (`app/bare-kit.h`)

The prebuild ships no bare-kit headers, so declare the worklet + IPC functions the host calls (RN does the same in `react-native-bare-kit/shared/BareKitModule.cc`). Opaque handle types; real `uv_buf_t` comes from `<uv.h>` (bare-headers). Keep the signatures byte-for-byte identical to bare-kit's headers - they are the ABI against the prebuilt `.so`.

```c
#include <uv.h>

typedef struct bare_worklet_s bare_worklet_t;
typedef struct bare_worklet_options_s bare_worklet_options_t;
typedef struct bare_ipc_s bare_ipc_t;
typedef struct bare_ipc_poll_s bare_ipc_poll_t;
typedef void (*bare_ipc_poll_cb)(bare_ipc_poll_t *, int events);

struct bare_worklet_options_s { size_t memory_limit; const char *assets; };
enum { bare_ipc_readable = 0x1, bare_ipc_writable = 0x2 };

int bare_worklet_alloc(bare_worklet_t **result);
int bare_worklet_init(bare_worklet_t *worklet, const bare_worklet_options_t *options);
int bare_worklet_start(bare_worklet_t *worklet, const char *filename, const uv_buf_t *source, int argc, const char *argv[]);
int bare_worklet_terminate(bare_worklet_t *worklet);
void bare_worklet_destroy(bare_worklet_t *worklet);

int bare_ipc_alloc(bare_ipc_t **result);
int bare_ipc_init(bare_ipc_t *ipc, bare_worklet_t *worklet);
void bare_ipc_destroy(bare_ipc_t *ipc);
int bare_ipc_read(bare_ipc_t *ipc, void **data, size_t *len);
int bare_ipc_write(bare_ipc_t *ipc, const void *data, size_t len);
int bare_ipc_poll_alloc(bare_ipc_poll_t **result);
int bare_ipc_poll_init(bare_ipc_poll_t *poll, bare_ipc_t *ipc);
void bare_ipc_poll_destroy(bare_ipc_poll_t *poll);
bare_ipc_t *bare_ipc_poll_get_ipc(bare_ipc_poll_t *poll);
int bare_ipc_poll_start(bare_ipc_poll_t *poll, int events, bare_ipc_poll_cb cb);

```

- [ ] **Step 4: Write the host** (`app/main.c`) - boot, send one message, await echo, exit

```c
#include "bare-kit.h" // forward decls (Task 0.2 Step 3); pulls in <uv.h> from bare-headers
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <uv.h>

// Read the packed bundle into memory; bare_worklet_start takes its bytes.
static uv_buf_t
read_file (const char *path) {
  FILE *f = fopen(path, "rb");
  if (!f) { perror("fopen"); exit(1); }
  fseek(f, 0, SEEK_END);
  long n = ftell(f);
  fseek(f, 0, SEEK_SET);
  char *buf = malloc(n);
  fread(buf, 1, n, f);
  fclose(f);
  return uv_buf_init(buf, (unsigned int) n);
}

static uv_sem_t got_reply;

static void
on_readable (bare_ipc_poll_t *poll, int events) {
  bare_ipc_t *ipc = bare_ipc_poll_get_ipc(poll);
  void *data;
  size_t len;
  int err = bare_ipc_read(ipc, &data, &len);
  if (err == 0) {
    printf("echo: %.*s\n", (int) len, (char *) data);
    uv_sem_post(&got_reply);
  }
}

int
main (int argc, char **argv) {
  uv_sem_init(&got_reply, 0);

  bare_worklet_t *worklet;
  bare_worklet_alloc(&worklet);

  bare_worklet_options_t options = {0};
  bare_worklet_init(worklet, &options);

  uv_buf_t source = read_file("app/app.bundle");
  bare_worklet_start(worklet, "/app.bundle", &source, 0, NULL);

  bare_ipc_t *ipc;
  bare_ipc_alloc(&ipc);
  bare_ipc_init(ipc, worklet);

  bare_ipc_poll_t *poll;
  bare_ipc_poll_alloc(&poll);
  bare_ipc_poll_init(poll, ipc);
  bare_ipc_poll_start(poll, bare_ipc_readable, on_readable);

  const char *msg = "ping";
  bare_ipc_write(ipc, msg, strlen(msg));

  uv_sem_wait(&got_reply);

  bare_ipc_poll_stop(poll);
  bare_ipc_poll_destroy(poll);
  bare_ipc_destroy(ipc);
  bare_worklet_terminate(worklet);
  bare_worklet_destroy(worklet);
  free(source.base);
  return 0;
}
```

> Validation note: two things to confirm at first build - the `bare-headers` include dir (the CMake guesses `node_modules/bare-headers/include`; check the package's actual layout) and that the forward declarations in `app/bare-kit.h` match the prebuilt `.so` exactly. Copy the signatures from bare-kit's `shared/worklet.h` / `shared/ipc.h` rather than retyping them - a mismatch surfaces as a link error or runtime crash, not a compile error.
